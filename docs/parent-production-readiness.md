## OpenAI branding decisions

Use CaseLink’s own name and mark as primary branding. Preserve text recognition and the accurate grant acknowledgment. Do not generate an imitation Blossom, merge an OpenAI mark into the CaseLink logo, recolor or distort an official mark, or imply a joint product. An OpenAI partnership lockup requires the applicable approvals; the existing recognition is not a general logo license. If an authorized official asset is used, retain its prescribed form, clear space and attribution, with CaseLink clearly identified. These decisions follow the [current official brand guidelines](https://openai.com/brand/).

API use and ChatGPT Futures recognition are separate facts. The product uses OpenAI Responses where configured; it does not require the parent’s personal ChatGPT account. Do not advertise a live model or transport when the runtime is in deterministic preparation mode or waiting for an enabled connection. Published model claims must match the deployed configuration.

## Data-purpose and deletion decisions

Using old credentials must be a convenience, not implicit consent to the new service. Enrollment creates the parent purpose; the request mandate and document consent separately authorize specific processing and actions. Reuse only source-backed household facts obtained for that parent purpose and permitted route. Existing school context must not silently populate intake, become model input or be disclosed to a partner.

Parent deletion immediately stops future parent work and begins removal of parent-purpose records/files. The retention runtime must never delete a reused Supabase Auth identity or cascade school records. Minimal tombstones/evidence, processor copies, delivered records and backups have distinct retention; the public notice explains the distinction. Full identity deletion and a school-record request need a separate verified disposition. Do not promise immediate global erasure or call retained hashes anonymous without assessment.

## Primary-source research and implications

The [PA breach statute](https://www.legis.state.pa.us/WU01/LI/LI/US/HTM/2005/0/0094..HTM), [FTC health-breach rule](https://www.ecfr.gov/current/title-16/chapter-I/subchapter-C/part-318), [HHS business-associate guidance](https://www.hhs.gov/hipaa/for-professionals/privacy/guidance/business-associates/index.html), [FTC COPPA guidance](https://www.ftc.gov/business-guidance/resources/complying-coppa-frequently-asked-questions) and [Education Department school-official guidance](https://studentprivacy.ed.gov/faq/when-does-school-official-exception-allow-school-or-lea-non-consensually-disclose-education) were rechecked for this continuity pass. Their requirements depend on actual data, actors and roles. The detailed applicability matrix and incident thresholds remain in the [privacy assessment](parent-privacy-regulatory-review.md), rather than repeating a second legal checklist here. The [official PA HB78 history](https://www.palegis.us/legislation/bills/2025/hb78) still shows October 6 removal from the Senate table, not enactment.

The [OpenAI data-control documentation](https://developers.openai.com/api/docs/guides/your-data) does not make `store:false` equivalent to approved Zero Data Retention. Final public processor promises must match the actual account, endpoint, enabled features and executed terms. Keep provider retention distinct from CaseLink’s own deletion schedule.

No hosted database migration, vendor setup, logo-permission request, external submission, family-data processing, deployment or production compliance attestation was performed in this review. Store executed agreements and sensitive operating evidence in restricted records, not in this repository.
