# Parent implementation progress

Updated October 26, 2026. Implemented locally on `main` from the preserved school baseline, `codex/case-manager-baseline-2026-10-25` at `700bb46`. Product authority is the [PRD](parent-support-mvp-prd.md) and [implementation plan](parent-support-implementation-plan.md). No hosted migration, deployment, real-family data, partner application or external support notification was used. The approved live model tests used synthetic cases only.

The product owner's priority is finishing the MVP. Privacy research and external decisions remain recorded launch work; they do not stop synthetic development, visual iteration or implementation. Concrete security and workflow defects are fixed as part of the product.

## Local preview

The production preview listens only on `http://127.0.0.1:3200` and stays in the background. Default `npm run parent:preview` uses synthetic placeholder credentials. The explicit `--local-services` build/start mode uses the isolated local Auth/Data API/Storage and test inbox, never the hosted school project. Visual/UX fixtures and real-service tests are separate; neither enables external program delivery.
