# SNAP provider contract: official-source research

**Checked:** October 26, 2026 (America/New_York). **Scope:** public, official Pennsylvania and federal sources only. No applicant information, credentials, organization registration, external message, signature, CAPTCHA solution or government application was submitted. This research does not establish an approved CaseLink submission connection or complete milestone B.

The most promising route is the existing citizen/guest application with a genuine provider-verification handoff, followed by independently verified filing and status access. A family does **not** need to register as a Community Partner. The separate current Pennsylvania application tracker also provides a potential status route without a COMPASS login or SSN when the application number is available. Browser assistance and data storage still need their own permission, isolation and tested resumption evidence.

## What remains unknown

- **Automation permission:** public guidance supports helping another person apply, but the inspected sources do not state permission for CaseLink’s unattended software, remote-browser control, credential storage, automated status polling or delegated machine signing. No reviewed public API, partner sandbox or test-application route was located. This is not proof that one does not exist or that all assistance is forbidden.
- **Terms:** registration guides refer to the My COMPASS terms, Data Release Agreement and individual user release/confidentiality agreements. Their complete current agreement text was not obtained from these public guides. Do not mark that contract reviewed from the guide’s description of an acceptance step.
- **Live completion contract:** the exact current SNAP-only conditional fields, whether/how the guest path implements minimum filing, certification wording, accepted signature process, error recovery, receipt fields, duplicates and later document/status transitions have not been rehearsed with an approved applicant or provider test facility.
- **Verification/resumption:** the existing [read-only browser evidence](parent-snap-browser-feasibility.md) reaches Family Safety and the actual DHS verification error before household entry. A reCAPTCHA frame alone is not proof of a necessary manual act. No reviewed parent takeover and confirmed agent resumption exists. Do not bypass or manufacture a successful verification result.
- **Submission transport:** a public paper/fax option is not an approved autonomous CaseLink transport. Confirm the correct CAO endpoint, permitted signature and evidence of delivery/filing before enabling one. An email address used for Community Partner support is not an applicant-data submission endpoint.

## Practical connection choices and next acceptance steps

1. **Citizen/guest browser route first.** Prove one isolated actual session reaches the provider barrier and reports it truthfully. Review the provider/tool requirements for a genuine parent-controlled verification handoff; only mark resumed after the same owned session reaches the next expected screen. Keep all applicant fields and filing controls disabled until the later field/signature/transport contract is inspected and reviewed. Do not route ordinary parents through Community Partner registration.
2. **Use an actual approved organizational route if available.** An existing partner may already have eligible Community Partner access. CaseLink would need that organization’s actual authority, user/data agreements and permitted technical arrangement, including whether automated assistance is accepted. Alternatively, the owner can pursue genuine organizational enrollment. Registration and agreement acceptance are consequential owner acts, not fictional automated setup. The official support mailbox is `RA-PWCOMPASSCP@pa.gov` in the registration materials; nobody was contacted in this research.
3. **Inspect status independently.** The official [tracker](https://trackmybenefits.pa.gov/) is a narrower candidate than storing a parent’s COMPASS password. Inspect its public entry, account-free input alternatives, current terms and validation without submitting invented identities. Later prove a real authorized exact-match result and subsequent changes before claiming status synchronization. Guest e-form/password access is an alternative whose secret-handling and permitted use need review.
4. **Preserve minimum-filing alternatives.** Keep official application access available while full automation is blocked. A reviewed paper/fax route may be a separate completion path, but it needs its own real signature, delivery, receipt and follow-up rehearsal. Do not silently substitute an operator or exported PDF for the promised autonomous completion.

**Piece-completion evidence:** public sources and limitations above are recorded; no source establishes that the whole COMPASS connection works. Independent review and live verification must precede enabling any new external capability. Protected identity capture, applicant trials, actual filing and agency-status retrieval were not performed.
